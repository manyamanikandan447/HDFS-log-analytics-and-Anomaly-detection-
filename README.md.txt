# Application Log Analytics & Anomaly Detection

## Overview

This project analyzes HDFS system logs and detects anomalous behavior using machine learning techniques.

## Dataset

HDFS_v1 Log Dataset

## Features

- Log Parsing
- Feature Engineering
- KPI Monitoring
- Trend Analysis
- Sequence Analysis
- Anomaly Detection

## Machine Learning Models

- Isolation Forest
- Local Outlier Factor (LOF)
- One-Class SVM

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-Learn
- Fatsia
- Streamlit
